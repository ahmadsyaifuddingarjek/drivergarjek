🚀 Panduan Setup Database Google Sheets & Deployment Google Apps Script GARJEK DriverPanduan ini berisi langkah demi langkah untuk menghubungkan Website Pendaftaran Driver GARJEK dengan Google Sheets dan Google Drive Anda sebagai database otomatis tanpa perlu server berbayar.📌 Langkah 1: Buat Google Spreadsheet BaruBuka Google Sheets.Buat Spreadsheet Baru (Blank Spreadsheet).Beri nama file Spreadsheet, contoh: GARJEK_DATABASE_DRIVER.📌 Langkah 2: Buka Google Apps Script EditorDi dalam Spreadsheet tersebut, klik menu Extensions (Ekstensi) -> Apps Script.Hapus semua kode default yang ada di dalam berkas Code.gs.Salin seluruh isi kode dari file Code.gs yang telah disediakan, lalu Paste di editor Apps Script.Klik ikon Save (Simpan / Ctrl+S).📌 Langkah 3: Jalankan Setup Database OtomatisDi bagian atas editor Apps Script, pilih fungsi setupDatabase pada menu drop-down fungsi.Klik tombol Run (Jalankan).Saat pertama kali dijalankan, Google akan meminta Izin Otorisasi:Klik Review permissions.Pilih Akun Google Anda.Klik Advanced (Lanjutan) -> Klik Go to Untitled project (unsafe).Klik Allow (Izinkan).Periksa Google Spreadsheet Anda: sheet Data_Driver, sheet System_Logs, dan folder Google Drive GARJEK_BERKAS_DRIVER_UPLOADS akan otomatis dibuat secara rapi.📌 Langkah 4: Deployment Google Apps Script sebagai Web AppDi pojok kanan atas editor Apps Script, klik tombol Deploy -> New deployment.Klik ikon Roda Gigi ⚙️ di samping Select type, pilih Web app.Isi konfigurasi sebagai berikut:Description: GARJEK Driver API V1Execute as: Me (email-anda@gmail.com)Who has access: Anyone (CRITICAL/WAJIB: Harus memilih 'Anyone' agar website front-end dapat mengirim data tanpa kendala CORS/Otorisasi Login).Klik tombol Deploy.Salin Web App URL yang diberikan (URL harus berakhiran /exec, bukan /dev).📌 Langkah 5: Hubungkan Web App URL ke Website Front-End (Detail Lanjutan)Langkah ini bertujuan untuk menyambungkan tampilan website (index.html) dengan backend Google Apps Script yang telah di-deploy.5.1. Membuka File Front-End (index.html)Buka file index.html di komputer Anda. Anda bisa membukanya langsung dengan cara klik ganda (double click) file tersebut di web browser (Google Chrome, Edge, atau Firefox), atau mengunggahnya ke hosting (GitHub Pages, Vercel, Netlify, cPanel, dll.).5.2. Menginput URL Endpoint Google Apps ScriptPerhatikan bagian paling atas halaman website GARJEK. Terdapat Bilah Hitam Top Banner khusus konfigurasi API.Cari kolom input bertuliskan GAS Web App URL: (#gasUrlInput).Tempelkan (Paste) URL Google Apps Script yang Anda salin pada Langkah 4 (Poin 5) ke dalam kolom input tersebut.Contoh bentuk URL yang benar:https://script.google.com/macros/s/AKfycbxXXXXXXXXXXXXX_EXAMPLE/execCatatan Penting: Pastikan URL tidak terpotong dan berakhiran /exec. Jika berakhiran /dev, sistem tidak akan berjalan untuk publik.5.3. Menyimpan Endpoint ke Browser (LocalStorage)Setelah memasukkan URL, klik tombol Simpan Endpoint.Sistem akan menampilkan notifikasi Toast Notification berwarna hijau di pojok kanan bawah bertuliskan:"Endpoint Google Apps Script berhasil disimpan!"Mekanisme Storage: URL ini secara otomatis tersimpan di localStorage browser pengguna (GARJEK_GAS_URL). Artinya, Anda tidak perlu memasukkan ulang URL ini setiap kali membuka atau memuat ulang (refresh) halaman website.5.4. Pengujian Koneksi Realtime (Testing)Untuk memastikan koneksi antara Front-End dan Google Sheets backend berjalan sempurna, lakukan tes berikut:Tes Cek Status NIK:Pindah ke tab Cek Status NIK.Coba ketik NIK sembarang 16 digit (contoh: 3275010203040005) lalu klik Cek.Apabila muncul pesan NIK tidak ditemukan dalam sistem GARJEK, artinya koneksi read (GET) ke Google Sheets BERHASIL.Tes Dashboard Admin:Pindah ke tab Dashboard Admin.Masukkan Login: Username admin dan Password admin123.Klik Masuk Dashboard, lalu klik tombol Refresh Data.Jika tabel memuat tulisan Belum ada pendaftar di Google Sheets, artinya koneksi Admin API BERHASIL.Tes Pendaftaran Driver Baru:Isi form pendaftaran pada tab Form Pendaftaran lengkap beserta unggahan file dummy.Klik tombol KIRIM PENDAFTARAN.Tunggu proses upload. Jika sukses, cek Google Sheets Anda pada sheet Data_Driver dan folder Google Drive GARJEK_BERKAS_DRIVER_UPLOADS. Data dan file foto akan otomatis bertambah secara realtime!🛠️ Panduan Troubleshooting & Mengatasi Error KoneksiJika terjadi kendala saat menghubungkan front-end ke Google Apps Script, periksa solusinya di bawah ini:Kendala / Pesan ErrorPenyebab UtamaSolusi / Cara MengatasiError Koneksi ke Google Sheets: Failed to fetchURL belum di-set atau pengaturan Who has access saat deploy salah.1.
